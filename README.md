# Sohail Birthday — Reenaz ♡

A responsive, front-end-only birthday/love story website made with:

- HTML
- CSS
- Vanilla JavaScript
- Your uploaded photos
- No backend
- No framework
- GitHub Pages compatible

## Files

- `index.html` — page structure/content
- `style.css` — responsive design and animations
- `script.js` — counter, modals, clickable messages, hearts, music button
- `images/` — your six uploaded images
- `.nojekyll` — keeps GitHub Pages from trying to process the site as Jekyll

## Run locally

Open `index.html` in a browser.

For the best local experience, you can also use VS Code + Live Server.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `sohail-birthday`.
2. Upload everything in this folder, keeping the `images` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will publish the site. It can take a few minutes to appear.

GitHub Pages supports static HTML/CSS/JavaScript sites.

## Optional music

If you want background music, place your own audio file beside `index.html` and name it:

`music.mp3`

The Music button will play/pause it. Browsers generally block automatic audio playback, so the visitor needs to tap the button.
